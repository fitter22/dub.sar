# Cuneiform Signs Reference

DUB.SAR uses standard Unicode cuneiform signs (Unicode range `U+12000` to `U+123FF`).

---

| `𒁹` | `U+12079` | diš | Single vertical wedge (one) |
| `𒁾` | `U+12081` | dub | Clay tablet |
| `𒊬` | `U+122AC` | sar | Inscribe, write |
| `𒅗` | `U+12157` | ka | Mouth, decree |
| `𒍣` | `U+12363` | zi | Breath, rise, add |
| `𒋫` | `U+122EB` | ta | From, deduct |
| `𒊭` | `U+122AD` | ša | Of, multiply |
| `𒉌` | `U+1224C` | ni | Oil, share, divide |
| `𒅁` | `U+12140` | íb | Hip, side, square |
| `𒁀` | `U+12040` | ba | Allot |
