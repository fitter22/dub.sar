# Reference

Comprehensive reference manuals for the DUB.SAR language, cuneiform sign repertory, units, command-line interface, and error diagnostics.

---

## Reference Manuals

- **[Keywords & Verbs](language.md)**: Formal lexical keywords, punctuation, operators, and reserved identifiers.
- **[Cuneiform Signs](cuneiform.md)**: Authentic Unicode cuneiform glyphs, transliterations, and meanings.
- **[Numeric Notation](numbers.md)**: Decimal, sexagesimal, fractional, and regular number formats.
- **[Units of Measurement](units.md)**: Complete catalog of supported SI and Mesopotamian metrological units.
- **[CLI Reference](cli.md)**: Flags, options, and commands for the `dubsar` toolchain.
- **[Diagnostics & Errors](diagnostics.md)**: Error classifications, diagnostic output format, and troubleshooting.
