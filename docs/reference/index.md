# Reference

The DUB.SAR Reference manuals provide complete, concise, and searchable technical specifications for the language syntax, runtime commands, metrological units, cuneiform signs, and diagnostic errors.

---

## Reference Manuals

| Manual | Description | Key Topics |
| :--- | :--- | :--- |
| **[Language Reference](language.md)** | Complete formal specification of language constructs, keywords, and grammar rules. | Tablet structure, quantities, expressions, postfix verbs, mathematical determinations, bounded domains, selection, sequences, archives, and modes. |
| **[CLI Reference](cli.md)** | Complete manual for the `dubsar` command-line toolchain. | Commands (`run`, `check`, `compile`, `format`, `transliterate`, `cuneiform`, `render`, `archive`), options, exit codes, and invocation examples. |
| **[Cuneiform Signs](cuneiform.md)** | Authentic Unicode cuneiform sign repertory and paleographic notes. | Historically attested mathematical ideograms, reconstructed operators, symbolic identifier signs, and Unicode codepoints (`U+12000`–`U+1247F`). |
| **[Numeric Notation](numbers.md)** | Numerical notation, sexagesimal radix mathematics, and exact precision. | Decimal integers, rational fractions ($p/q$), positional base-60 sexagesimals, regular numbers, and arbitrary-precision rational model. |
| **[Units of Measurement](units.md)** | Catalog of supported metrological dimensions and scaling factors. | Standard physical dimensions (`time`, `mass`, `length`, `month`, `year`), conversion ratios, and custom dynamic units. |
| **[Diagnostics & Errors](diagnostics.md)** | Error classification, dual-script error reporting, and troubleshooting. | Diagnostic box format, error types (`DubSarSyntaxError`, `DubSarUnitError`, etc.), and coordinate indicators. |
