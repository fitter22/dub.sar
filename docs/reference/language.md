# Keywords & Verbs Reference

This document catalogs the complete keyword and verb vocabulary for DUB.SAR in both Scholar and Tablet modes.

---

## Structural Keywords

| Scholar Keyword | Cuneiform Sign | Category | Description |
| :--- | :--- | :--- | :--- |
| `problem` | `𒂊𒁹` | Section | Marks the beginning of the problem statement. |
| `recipe` / `procedure` | `𒁾𒊬` | Section | Defines a reusable procedure. |
| `result` | `𒅗𒁹` | Section | Specifies the final inscribed output. |
| `when` | `𒂊𒀀` | Conditional | Conditional execution branch. |
| `else` | `𒉡𒂊𒀀` | Conditional | Alternative execution branch. |
| `consider` | `𒄀` | Loop | Bounded domain iteration. |
| `through` | `𒌗` | Loop | Specifies upper bound of iteration. |
| `retain` | `𒋼` | Selection | Retains optimal candidate. |
| `return` | `𒄑` | Control | Returns from procedure. |
