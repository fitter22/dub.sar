DUB.SAR

Mathematical programming in the style of the tablet.

A tablet states a problem, carries out a recipe, and inscribes a result. Quantities keep their units. Arithmetic stays exact. The same tablet can be written in Latin, in cuneiform, or in both.

Try a tablet Read the tutorial

A program is an inscription

  1. Problem. Name the given quantities and the units they carry.
  2. Recipe. Describe the calculation. Scholar tablets name each intermediate. Tablet-mode tablets stack values and apply an operation to the top of the stack.
  3. Result. Inscribe the conclusion. The playground prints that inscription.

The same hypotenuse, two scribal habits

Both tablets below find the hypotenuse of a 3-by-4 right triangle. Tablet mode is its own notation. It is not a Latin program with the letters swapped for signs. The scholar tablet names w_sq, h_sq, and hyp. The cuneiform tablet squares, adds, and takes a square root without those names. Both inscribe 5 meter.

What the language keeps

  • Exact quantities

    Sexagesimal rationals, not floating point. A reciprocal that exists on a tablet stays exact.

  • Units

    Meters, cubits, and derived dimensions travel with the number. A mismatched unit is an error.

  • Three writings

    Scholar, tablet, and mixed modes compile to the same meaning. Mixed tablets may use cuneiform syntax with Latin names.

  • Bounded search

    Iteration has a stated range. A tablet does not wander in an open loop.

  • The archive

    Reference tablets, including reciprocal tables, can be consulted from the school archive.

  • Several targets

    The same source runs on the interpreter, the bytecode machine, and a WebAssembly lowering.
